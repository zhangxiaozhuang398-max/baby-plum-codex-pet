# 糖梅宝宝 Codex 桌宠

这是根据游戏 Wiki 公布的糖梅宝宝原版像素素材与待机动画参数重建的 Codex v2 动画桌宠包。

## 当前效果

- 名称：糖梅宝宝
- 待机动作：按照原版 30 FPS、16 帧参数原地飞行
- 画面：使用原版透明像素精灵，不再从视频画面抠图
- 阴影：保留原版连续暗红阴影与黑色外轮廓，不含视频扫描条纹
- 不启用鼠标方向跟随
- 不包含点击互动动作

## 文件

- `pet.json`：桌宠配置
- `spritesheet.png`：透明背景动画精灵图（Codex v2）

## 本地安装

将仓库中的 `pet.json` 和 `spritesheet.png` 放入：

```text
%USERPROFILE%\.codex\pets\video-red-pet\
```

随后在 Codex 的桌宠设置中选择“糖梅宝宝”。

本仓库为私有备份仓库。
