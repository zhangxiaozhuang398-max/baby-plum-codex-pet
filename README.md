# 糖梅宝宝 Codex 桌宠

这是从参考视频提取并整理的 Codex v2 动画桌宠包。

## 当前效果

- 名称：糖梅宝宝
- 待机动作：按照参考视频原地快速飞行
- 不启用鼠标方向跟随
- 不包含点击互动动作

## 文件

- `pet.json`：桌宠配置
- `spritesheet.png`：透明背景动画精灵图（Codex v2）

## 本地安装

将仓库中的 `pet.json` 和 `spritesheet.png` 放入：

```text
%USERPROFILE%\.codex\pets\video-red-pet\
```

随后在 Codex 的桌宠设置中选择“糖梅宝宝”。

本仓库为私有备份仓库。
